Level 1

Module A: the transistor as a switch

Input → transistor → LED. Vary the input and read the classical bit from what the circuit does.

A

Theory

The switch model (BJT)

An NPN transistor conducts only when the base-emitter junction is forward biased. Base current is set by the base resistor; collector current follows until the load limits it.

$$I_B=\frac{V_{in}-V_{BE}}{R_B},\qquad I_C=\min\!\left(\beta I_B,\; \frac{V_{CC}-V_{CE,sat}}{R_L}\right)$$
$$V_{out}=V_{CC}-I_C R_L$$

The switch model (MOSFET)

An NMOS transistor conducts when the gate-source voltage exceeds the threshold. With a resistive load it moves from cutoff to saturation to the triode (ohmic) region.

$$I_D=\tfrac{k}{2}(V_{GS}-V_{th})^2\quad (V_{DS}\ge V_{GS}-V_{th})$$
$$I_D=k\!\left[(V_{GS}-V_{th})V_{DS}-\tfrac{V_{DS}^2}{2}\right]\quad (\text{triode})$$

From voltage to bit

Information is stored as a voltage level, then compared to a threshold. Below it we read 0, above it 1. This is the whole idea of a classical bit.

$$b=\begin{cases}1 & V_{in}>V_{th}\\ 0 & V_{in}\le V_{th}\end{cases}$$
$$P_{diss}=V_{CE}\,I_C$$

The LED sits in series with the load: its brightness follows IC. A common-emitter stage also inverts: when the transistor is ON, Vout is low. That is the NOT gate of Module B.

Level 2

Module B: logic gates

Combine switches into gates. Build NOT, AND, OR, NAND, NOR and XOR, then meet the quantum NOT.

B

Theory

Boolean algebra

$$\text{NOT: } \bar A \quad \text{AND: } A\cdot B \quad \text{OR: } A+B$$
$$\text{NAND: } \overline{A\cdot B}\quad \text{NOR: } \overline{A+B}\quad \text{XOR: } A\oplus B=A\bar B+\bar A B$$
$$\overline{A\cdot B}=\bar A+\bar B\qquad \overline{A+B}=\bar A\cdot\bar B\quad(\text{De Morgan})$$

NAND is universal

Every gate above can be built from NAND alone. For example NOT is NAND(A,A) and XOR needs four NANDs. The lab shows the internal nodes for the gate you select.

In CMOS a NAND needs only 4 transistors, which is why it is the workhorse of digital design.

Voltages decide the logic

A gate must restore a degraded input to a clean level. The inverter transfer curve shows how, and the noise margins say how much disturbance a logic level can survive.

$$NM_H=V_{OH}-V_{IH},\qquad NM_L=V_{IL}-V_{OL}$$
Quantum counterpart. The NOT gate is a matrix acting on a state: $$X=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad X|0\rangle=|1\rangle,\quad X|1\rangle=|0\rangle.$$ Unlike AND and OR, which throw information away, every quantum gate is reversible.

Level 3

Module C: bit to qubit

Same idea of a two-state system, one new ingredient: amplitudes. Explore a single qubit, then build circuits.

C

Theory

Bit and qubit

$$b\in\{0,1\}$$
$$|\psi\rangle=\alpha|0\rangle+\beta|1\rangle,\quad |\alpha|^2+|\beta|^2=1$$

\(\alpha\) and \(\beta\) are complex amplitudes. They are not voltages and cannot be read directly.

Measurement

Reading a qubit always gives 0 or 1, exactly like reading a transistor output. The difference is that the result is random, with the Born-rule probabilities, and the state collapses afterwards.

$$P(0)=|\alpha|^2,\qquad P(1)=|\beta|^2$$

Bloch sphere

Every single-qubit pure state is a point on a sphere, set by two angles.

$$|\psi\rangle=\cos\tfrac{\theta}{2}|0\rangle+e^{i\varphi}\sin\tfrac{\theta}{2}|1\rangle$$

A classical bit can only sit on the north or south pole.

Lab 1: the same function on both machines

Reading the result. The classical side is deterministic until noise pushes a voltage across the threshold. The quantum side is probabilistic by design: with basis inputs you want one outcome near 100%, with superposition inputs the circuit evaluates all input pairs at once and measurement samples one of them. The AND gate uses a Toffoli (CCX) because quantum gates must be reversible.

Lab 3: quantum error correction

The 3-qubit repetition code stores one logical qubit in three. Two or more flips are needed to fool it.

$$|\psi\rangle=\alpha|0\rangle+\beta|1\rangle\;\to\;\alpha|000\rangle+\beta|111\rangle,\qquad p_L=3p^2-2p^3$$

Logical error against physical error

Below p = 0.5 the code wins. For small p the logical error is about 3p².
